# 🪨📄✂️ Rock, Paper, Scissors — Python Game

A simple console-based Rock, Paper, Scissors game written in Python. Play against the computer, keep going as long as you like, and type `quit` to exit anytime.

## 🎮 Features

- Human vs. Computer gameplay
- Type the **full word** (`rock`, `paper`, `scissors`) **or a shortcut** (`r`, `p`, `s`)
- Input is case-insensitive (e.g. `Rock`, `P`, `S` all work)
- Friendly win/lose/tie messages
- Type `quit` to end the game politely

## 🚀 Getting Started

### Prerequisites
- Python 3.x installed on your machine

### Run the game

```bash
python rock_paper_scissors.py
